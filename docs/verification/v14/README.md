# v14 Orion 持久海盗生态验证

基线为 `main / ff1a12b`。Orion 单舰抢货与瞬时补舰逻辑已替换为私有情报、行动编队、实体运输和付费生产。普通海盗及交货策略使用确定性游戏 AI；己方 Agent 继续走现有模型、校验、命令和自愿协作接口。

| 场景                                          | 实测结果                                                                                                                                            |
| --------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |

| 同场景持续至360分钟                           | 两次矿场行动共取走250单位；实际回库并向黑市交付62.5单位材料，取得312.5 Credits；两艘原 Raider 永久损失，付费补舰恢复舰队                            |

| 200单位运输舰，保船策略／Admiral 同意         | 交货50，保留150；完成后停止抢货，赃物实际运回、卸货、销赃                                                                                           |

| 600单位满载舰，大宗掠夺                       | 多舰登舰并实际会合转运至 Smuggler，共取走300，留存300；双方及黑市库存守恒                                                                           |
| Logistics 请求 Battle 救援并获接受            | 本地 provider 选择真实 reinforce / ESCORT；救援到场使海盗撤离，运输舰安全抵港，货损0，契约履约及经验／关系结算                                      |

自然航运不保证遭到勒索：Dawn 的火控、周边设施和已观测军舰会使海盗放弃或转向矿场。`natural-worlds.json` 保留各 seed 的120／360分钟状态、行动、实际抢货、收入、损失和付费生产，不能把指定600单位运输意图误认为每趟都实际装满600。

## 自动验证

- `npm test`：24文件、361项通过。覆盖真实传感器和分跳报告、未知指令／路径不提供情报、协同截击、失联放弃、交货覆盖、暂停、实际运动中断登舰、多舰转运、批次去重、真实货损与交付 XP。
- 经济验证覆盖买方预算／仓满、整数弹药、维修／装弹、五舰型付费造舰、获利后扩军、在建额度、摧毁基地、残余重建及彻底灭失。
- 同 seed、固定命令流验证1×／4×／16×。集结、登舰、撤离、补给、造舰和现场施工保存重载后，库存、收入及资产生成不重复。既有反跟踪、秘密尾随和十分钟基地确认回归保留。
- `npm run build`：严格 TypeScript、Vite 和 Electron 主进程构建通过。
- Electron 全套62项通过；最后修正救援实际到场时间后，重新通过5项 Orion Electron 场景及全部361项规则测试。最终结果记录于 `checks-summary.json`；只使用隔离 userData 和本地 HTTP provider，所有真实 API 凭据均不读取。
