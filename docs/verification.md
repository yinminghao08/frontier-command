# V1 验证记录

验证日期：2026-09-26。平台：Windows，Electron 41，项目锁文件中的依赖版本。

## 源码与规则

- TypeScript 检查与 Vite／Electron 生产构建成功。
- Vitest：25 项测试通过，覆盖三类任务、并行执行、收益只结算一次、航线、探索风险、Klingon／Romulan 处置、损伤、拖回、维修、权限、暂停、确定性及存档恢复。
- Playwright：3 项真实 Electron 测试通过。覆盖派遣、键盘移动、接管与释放、禁用倍速、导航、保存重启、扫描开火警告、失焦暂停、探索选择、结算显示、损坏存档保护及归档重置。
- Prettier 检查通过。

## 界面

实际 Electron 内容视口覆盖 1280×720、1440×900、1920×1080。自动断言侧栏宽度分别为180／200／240 CSS px，横条为20／24／28 CSS px，外侧弯角为100／130／160 CSS px；无页面级横向溢出。

截图已人工阅读，检查双肘形连接、黑色间隔、字体、侧栏标签、探索决策、结算和损坏存档状态。截图来自真实 Electron 隐藏窗口，不是浏览器伪造世界预览。机器使用125%显示缩放，因此PNG物理像素比CSS视口大。

1280×720下推进、转向、开火、恢复任务按钮可见。主内容与右侧状态区独立滚动，操舰命令置顶并固定；小窗口查看舰船状态与任务全文时需要滚动。参考首页保留双肘形、条带比例、Classic配色和右侧胶囊导航，网站文章替换为游戏内容，随机数字区删除。

代表截图见 `screenshots/`。其他场景截图由 `npm run test:e2e` 输出到项目 `test-results/`。

## 发布验证

发布程序与压缩包的独立验证结果见发布目录中的 `release-verification.txt`。复现命令：

```powershell
npm run package
npm run test:package
npm run package:zip
npm run test:release
```

`test:release` 会将ZIP解压到新临时目录，运行其中的实际EXE，在断网浏览器上下文中验证派遣、时间推进、保存和重启续玩。所有测试使用独立临时存档，未覆盖玩家存档。

## 限制

- 本阶段仅LV1；规则自动驾驶不代表已实现模型Agent，资源计数不代表成长系统。
- 本次采用后台真实Electron测试和截图检查，没有再次接管用户桌面进行人工点击。
- 发布程序未代码签名；未测试其他操作系统，也未以其他Windows机器作为独立兼容性样本。
- 原创局部星区、简化二维舰船与游戏数值，不宣称正史星图或Bridge Commander复刻。
