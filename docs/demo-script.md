# v6 Admiral 演示

## 默认新世界 / 1×

- 新世界暂停、1×。顶部是通信与战略状态，底部是四舰及当前指令；左侧 STARBASE 有八个模块。
- 选择 VERITY → 新指令 / 改令 → EXPLORE → UNKNOWN 0/-1 → Close Survey。
- HORIZON → MINE → 已确认的 Helios 矿物带 → base → 一次采集。
- MERIDIAN → HAUL → mine 到 base → Materials 100 → Direct。
- VIGIL → PATROL → outpost → 120 游戏分钟。点击继续。

约 1–2 分钟：发现新的 Sector、星系、行星、异常和矿藏。选择新资源点，可以 Mine；选星系/星球可改名。发现不会自动暂停或强制移动相机。

约 2–5 分钟：运输材料入库；用 VIGIL / INTERRUPT / REFIT 安装 Expanded Cargo，容量从 12 变为 62，完成后接续原巡逻。也可在 STARBASE / ENGINEERING 完成此操作。取消或替换矿工/运输舰，已装货物不会消失。

## 新发现 → 建设 → 物流

在 OPERATIONS 选择新发现、近距确认的资源点，建立 MINE 项目。在 COLONIES 打开项目，点击“安排建设物资 / 分批真实货运”，查看 FIFO 指令队列。项目先有现场实物库存，材料与补给齐备才施工；任何时候 Admiral 可以调走货船。

星系可建 OUTPOST；宜居星球可建 COLONY。矿场持续消耗 Supplies 和有限矿藏；殖民地消费 Supplies 并产生预算；前哨扩展传感器和航线节点。

## 价值 → Orion → Security

观察 Helios / 新矿场库存和货船航迹。侦察舰收集实际情报；货值增长、护航薄弱时，持久 Raider 才出动。普通袭击通信不暂停，需要 Admiral 留意。设施有独立护盾和相位炮，保留响应时间。

- Intercept：根据观测航迹截获。
- Escort：跟随实际货船，并按 ROE 保卫目标。
- Drive Off：警告相位炮施压，观测敌方风险撤退。
- Shadow：保持返航者接触，可能发现 Hideout。
- Attack / Disable：明确命令优先于 HOLD FIRE。Precision Targeting 可选择 Engines / Weapons。
- Retreat：随时替换当前行动，货物和损伤保留。

## 收益 → 成长 → 更远探索

在 STARBASE / LOGISTICS 出口实际 Materials，库存随之减少；升级 Logistics 后可循环运送矿场产出或殖民地 Supplies。SHIPYARD 支付材料/预算/补给造新舰，出现独立舰籍；DRYDOCK 维修；ARMORY 制造并按数量装载弹药。

Deep Scan 解锁隐藏异常；Long Range Sensors 增加感知和探索范围；Defense Grid 解锁前沿平台。不要把未确认敌对 Romulan 当成自动目标；跨境与攻击会提高 tension。

最后暂停 → ARCHIVE → 保存 → 重启，检查发现、名称、项目、模块、舰籍和永久历史保持。重大舰损保留，新舰不复活旧舰；Dawn 被毁可从封存时间线恢复昨日新分支。
