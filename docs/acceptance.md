# LV1 验收对照

## 官网要求与对应实现

| 要求 | 实现与观察方式 |
|---|---|
| 至少三种方向不同的任务 | 科学探索、后勤补给、边境巡逻，各两份初始任务 |
| 角色／操作者适配不同 | 探索受科学能力影响，补给受货舱容量限制，巡逻威慑受武器能力与识别状态影响 |
| 时间与注意力不同 | 探索有20秒调查选择窗口；补给可自动完成且有时限；巡逻包含扫描与接触处置 |
| 风险不同 | 近距调查直接辐射损伤；快速补给航线微陨石损伤；巡逻可能遭敌舰还击 |
| 收益类型不同 | 科研数据、前哨实际储备／行动配额、巡逻情报／威胁降低 |
| 后续成长价值清楚 | 各成果持久化为未来科研、后勤和防卫成长输入，当前不实现升级 |
| 真人参与实际决策 | 选择调查、改变航线、扫描警告、接管实时操舰与开火 |
| 可运行 demo | Windows Electron 打包目录无需Node或联网，源码可 npm start |

## 自动化验证

`npm test` 验证引擎和持久化。覆盖三类并行任务完整闭环、收益不重复、探索风险收益差异、航线与时限、货物回收、Klingon威慑、Romulan和平驱离、伤害与失能、免费抢修、指挥权限、非法参数、隐藏接触、接管互斥、暂停、存档版本、备份恢复及确定性复现。

`npm run test:e2e` 在实际 Electron 中验证启动、任务中心派遣、W键移动、接管时禁止倍速、释放控制、基地和档案导航、保存后重启恢复，以及战术场景的扫描、目标选择、开火、警告和失焦暂停。

端到端测试使用临时用户数据目录，不覆盖玩家存档。测试截图输出到 `test-results`，覆盖1280×720、1440×900与1920×1080窗口尺寸。

`npm run test:package` 启动实际发布exe的隐藏窗口，通过同一preload接口检查离线派遣、模拟推进、保存与重启恢复，不聚焦或操作桌面窗口。

## 手动检查

检查原生窗口的导航、行动卡片、中文文本、LCARS主框架、区域滚动、键盘与屏幕按钮，以及打包程序的首次启动。禁止将浏览器预览截图当作已经验证Electron运行的证据。

## 明确不计入本阶段

本版本没有模型调用、Agent人格、自然语言协商、装备升级、等级、基地建造、多人服务器、3D舰船控制或BC资源转换。自动驾驶不等于已完成Agent；成果计数不等于已完成LV2成长循环。
