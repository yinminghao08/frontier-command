# 新版 LV1 验收矩阵

对应题目：https://join.geek-tech.club/problems2/agent-mmo-game

## 任务机制差异

| 维度     | 防御／拦截                 | 运输                             | 探索／侦察                   |
| -------- | -------------------------- | -------------------------------- | ---------------------------- |
| 舰船适配 | 武器、护盾、速度；可多舰   | 货舱与存活能力；单舰             | 科学与传感器；单舰           |
| 注意力   | 目标、ROE、支援、撤退      | 路线、货种数量、护航；可自动执行 | 抵达决策、风险方案与敌情识别 |
| 失败条件 | 目标失能、超时、失联、撤退 | 时限、货物损失、失能、取消       | 搜索超时、辐射或交战撤退     |
| 真实消耗 | 舰体、核心、鱼雷           | 起点库存、航行／装卸时间、货物   | 能源、时间、近距辐射损伤     |
| 收益     | 安全、配额、情报           | 目的地真实库存、稳定配额         | 科研、调查记录、识别信息     |
| 后续价值 | 保障其他行动               | 支援与设施恢复                   | 已知风险与规划依据，成果保留 |

三类都从创建到执行、结算、返航、重新可派遣形成闭环；支持并发。不同机制有独立测试，不以名称或奖励数字替代玩法差异。

## 引擎验收

- 四联邦舰型、三罗慕兰舰型与海盗均配置化。
- 射程、冷却、命中、护盾、伤害、核心和弹药真实结算。
- 四种 ROE、撤退优先、隐形禁火与解除隐形过渡。
- 世界边缘生成与连续航行；海盗选弱目标、罗慕兰可不攻击。
- UNKNOWN 至 TRACKED 的分级投影、位置冻结、30分钟失效与重新发现。
- Snapshot／Observation 不含隐藏敌方实体、AI 意图、真实路线和随机源。
- 接受／修改命令原子校验；库存预留、回收与收益不重复。
- 同种子同命令序列复现；存档续跑与不中断模拟一致。
- Step 1 的固定步长、倍速、暂停、日界事件与控制器权限保留。

## UI 与 Electron 验收

- 星图常驻，六项侧栏、对象 Inspector、顶部通信与底部行动同步。
- 拖动、缩放、图层、地图选择和定位可以实际操作。
- 战斗配置、运输路线／数量、调查方案是真实引擎命令。
- 1280×720、1440×900、1920×1080 无页面级溢出；面板内容独立滚动。
- 实际 Electron 中通过 UI 派遣三类任务，处置调查、等待结算与返航，再保存并重启。
- 存档损坏时显示错误，提供归档重置，不覆盖旧代文件。
- 打包程序离线运行、创建 Order、时间推进和保存重启可验证。

## 存档与范围

只使用 world-v4.json 与同代备份；旧世界不迁移、不加载、不覆盖。v4 无法恢复时禁止保存临时世界，未知未来版本禁止覆盖。新世界重置归档 v4。

不计入本阶段：LLM、Agent成长／记忆／拒绝任务、Academy、造船、制造、完整经济、永久舰船损失。PERSONNEL 是固定规则操作者名册，不是培养系统。
