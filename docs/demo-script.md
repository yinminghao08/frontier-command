# 两分钟现场演示脚本

## 演示前准备

运行打包目录中的 Frontier Command.exe。系统页归档旧存档并重置，保持默认种子236807。关闭无关窗口，避免失焦导致模拟暂停。推荐1440×900或更大窗口。

先确认“继续”“任务中心”和右侧操舰按钮可见。低高度窗口的主区和遥测区可以分别滚动。不要临时配置任何模型API，LV1无需模型。

## 0:00—0:15 · 展示定位与分工

“这是 Starfleet 边境舰队管理的 LV1 世界原型。玩家指挥基地与三艘功能不同的星舰。自动驾驶是规则控制，未来 Agent 将通过同一组高层动作接入。”

任务中心依次派遣：明理号→琥珀星云；子午号→新曙殖民地安全补给；守望号→K-7巡逻。每次确认执行舰船。点击继续，切换4×。

## 0:15—0:40 · 展示探索的真实决策

选择明理号，等待进入异常调查窗口。选择近距调查。

“探索依赖科学能力和判断。近距调查带来更多样本，但引擎实际扣除舰体；远距调查更安全。收益不由文本描述决定。”

同时指出子午号装载的货物、交付时限与安全航线；可展示快速航线的说明，但此次不必改变。

## 0:40—1:05 · 展示边境与操舰

选择守望号，抵达K-7后立刻直接操舰。接管会自动切到1×。

扫描接触，选择已识别的 Klingon 目标。按 W 短促推进，必要时 A/D 修正朝向。舰艏朝向目标、距离145以内时发射一次相位武器，然后警告驱离。

“接管只影响这一艘舰；另外两艘继续工作。战斗与自动驾驶使用相同射程、冷却和护盾规则。巡逻也能靠识别和威慑完成，不必摧毁敌舰。”

若自动驾驶已经驱离目标，直接展示日志中的识别与警告结果，并短暂接管展示移动即可；无需为一次开火重做整段演示。

## 1:05—1:35 · 展示结算与返航

释放控制并恢复任务，回到4×。展示科研数据、补给交付和巡逻情报。打开行动日志查看三种不同的结算依据。

“规则决定真实结果。任务只结算一次，舰船随后返航。资源、任务阶段、损伤和时间都保存在程序中。”

进入舰队管理，给受损的明理号安排维修；材料不足时有较慢的基础抢修。

## 1:35—1:55 · 展示持久化与可扩展边界

暂停、系统页保存，正常关闭再启动，展示世界时间与任务状态保留。打开星区档案说明世界观文档与实现标记。

“当前仅做LV1。下一阶段可以扩展成长与Agent，但不会让模型直接修改世界状态。”

## 可复现的额外演示

Romulan 场景：守望号→R-3静默走廊，接近后扫描、识别、警告。侦察舰暴露后撤退，不需要战斗。

失败恢复：补给出航后保持位置直至超时，显示失败、返航和货物归还。失能／抢修路径由自动测试验证，现场不必花时间故意打至失能。

演示视频可只保留核心操作和结果片段，不把开发工具、测试环境或模型配置放进产品流程。
