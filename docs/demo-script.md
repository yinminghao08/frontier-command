# 两分钟演示脚本：Admiral 的三个决策

## 准备

使用1.1.0的完整Windows包。ARCHIVE → 新世界 → 归档并创建，回到固定种子236807、Day 1 00:00。不要加载旧版世界，也不要修改存档伪造结果。演示使用正式引擎及真实威胁。

## 00:00—00:35：建立并行行动

说明：“这是 LV1 确定性规则 AI，玩家是 Admiral，通过高层命令管理边疆。”

进入 OPERATIONS：

1. 新建运输：目标新曙殖民地，Antares，Dawn 出发、30补给、安全路线。
2. 新建防御：目标新曙殖民地，Peregrine，45游戏分钟，ENGAGE HOSTILES，默认舰体30%撤退。
3. 新建探索：琥珀星云，Constitution，保留远距方案。

展示货舱差异及四舰配置；Galaxy 留作增援。启动16×并继续。

## 00:35—01:05：观察真实世界

收起工作面板，展示三条路线和底部行动阶段。打开 Sensors 图层，说明基地不能看到罗慕兰全部动态。

海盗由边缘航行而来。新接触自动暂停：点击通信定位，解释 CONTACT／CLASSIFIED／IDENTIFIED。继续模拟。守望号保护运输窗口；海盗会因为护航或损伤撤退，不要求玩家逐帧操作。

## 01:05—01:30：调查决策

琥珀星云抵达后自动暂停。点击底部探索行动，选择“近距调查 · 高精度”，再继续。说明远距更安全，近距会造成实际辐射损伤、耗时更长、提高首次调查科研成果。

可点击明理号查看舰体与核心，再切回行动。若战场产生新关键事件，处理后继续，不将自动暂停误认为程序卡住。

## 01:30—02:00：结算、返航与价值

运输完成后查看殖民地库存增加；防御结束后显示安全结果；探索增加科研并留下调查记录。继续16×到返航归档，展示舰船解除占用。

在 STARBASE 选择受损舰船安排维修；在 ARCHIVE 展示收益和战报，保存。说明：“这一版的后续价值是后勤、安全和信息。升级、制造与 LLM 留给后续阶段。”

## 可自由试玩的分支

- 运输选大于Peregrine货舱容量的货物，观察无副作用的拒绝提示。
- 给防御行动添加Galaxy支援或修改为HOLD FIRE，观察真实交战政策。
- 点击中立区空白坐标创建侦察；未授权时拒绝，明确授权后可执行。
- 切换快速／安全航线，比较已知敌情出现后的路线。
- 查看失联接触：Last Known Position 不跟随敌舰移动，30游戏分钟后失效。
- 取消运输并返航，检查未装货预留释放或已装货物回收。

视频时长是讲解目标；不同点击速度和自动暂停次数会影响实际演示时间。完整闭环有自动化测试验证，不通过跳过引擎或修改世界来压缩演示。
