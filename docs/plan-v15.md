## 固定行为

- 清剿持续到玩家取消，仅使用公开情报。优先处理正在攻击己方的目标，其余按可见性、距离、稳定 ID 排序。
- 失联时接近最后观测位置并搜索；失败报告未确认战果，处理其他目标，同一份旧情报不重复追逐。等待新目标不宣称整个势力已经灭绝。
- 首次实际开火、击毁、失联和受阻由引擎报告；相同事件去重。模型的接受或拒绝、引擎执行回执和 API 错误显示不同来源。
- “运输直接装满货仓，立即执行”修改当前趟：在矿场就补装，已经出发就返回原源头补装，再送至原目的地；已装满时继续交付。路线、现有货物、预计补装量和 ETA 来自引擎。
- 普通改单和直接接管不自动扣信任、士气或增加不满。真实违约和损失仍有后果。
- Agent 关闭、API 未配置或认证失败也必须在原会话给出结果。明确发给 Agent 的消息不会静默丢失；没有可用 Agent 的按钮模式不能静默改成直接接管。

## 状态节奏

| 实际活动                       | 疲劳 / 游戏分钟 | 压力 / 游戏分钟 |
| ------------------------------ | --------------: | --------------: |
| 普通工作                       |           +0.25 |    安全时 −0.10 |
| 实际交战（含交战中的武器冷却） |           +0.50 |           +0.30 |
| 安全闲置                       |           −0.10 |           −0.20 |
| 安全停靠                       |           −0.25 |           −0.20 |
| 安全泊位执行休息               |           −0.75 |           −0.50 |

已观测近距威胁使压力每分钟 +0.15。每轮交战首次受击压力 +8；舰体首次跨过 75%、50%、30% 时分别压力 +5、信心 −3。安全十游戏分钟后结束交战事件，存档记录去重证据。

疲劳达到 80 后继续工作每分钟不满 +0.10；安全休息不满 −0.15。疲劳 50/80、压力 60、不满 50 触发合并决策事件，回落超过五点后才允许再次触发。稳定性格不随仪表变化。界面显示动态状态一位小数、速率和最近原因；连续小变化不刷聊天。

## 交付约束

所有回归使用隔离 userData 和本地 HTTP provider，不读取或调用玩家外部 API 凭据。本地接口测试只能证明消息大小、协议、截止、行为和界面；真实供应商回复速度需要以控制台的真实请求遥测评估，不能用本地 provider 的耗时替代。重启游戏后才能载入新的主进程和 v15 存档迁移。
