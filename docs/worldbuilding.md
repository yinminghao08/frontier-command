# 曙光边区：Admiral 指挥手册

## 定位与范围

玩家是 Dawn Starbase 的 Admiral，负责边疆交通、防卫与调查。世界采用 Star Trek 风格的原创边区；地点、舰队名、数值和跨时代舰型混编为游戏设定，不声称对应正史编制。

当前为 **LV1 确定性规则 AI**。Operator 是独立身份，每名规则操作者分配一艘舰船；舰船保存物理状态，操作者执行合法高层命令。没有模型调用、人格、记忆、拒绝命令、等级、学员或 Academy。科研和配额不解锁升级，不包含造船和制造链。

## 战略空间与时间

沿用 Step 1 的1600×800战略平面：

- Federation Space：x < 1040。
- Neutral Zone：1040 ≤ x < 1280。
- Romulan Space：x ≥ 1280。

Dawn Starbase 位于 (880,430)。新曙殖民地、信标前哨、中继站、赫利俄斯矿场、M级翠绿星、琥珀星云、回声异常与边境界标构成行动网络。矿场和M级行星可以成为地图或调查目标，不模拟自动采矿或殖民成长。

世界从 Day 1 00:00 暂停开始，每步0.1游戏分钟；1×、4×、16×只改变每次主进程调度的步数。新接触、确认敌对、调查决策、低舰体、失能和任务失败自动暂停，处理后需继续。计时器全部使用游戏时间。失焦仍自动暂停；重启不推进离线时间。

舰队停靠基地外围四个独立泊位，地图显示真实泊位坐标；返航必须飞回泊位。应急拖航是失能后的明确恢复机制。

## 高层命令与实际决策

Order 可由求援信息、地图选择或 OPERATIONS 创建。每舰只能执行一个行动，防御可多舰；运输与探索为单舰。Priority 实际影响通信排序及防御支援目标排序，不能提升舰船数值。

- **防御**：保护设施或舰船，计时只在保护范围内累计；有已知攻击者时不能提前宣告区域安全。拦截以观察到的击毁或撤出为依据，失联搜索超时是失败。
- **运输**：可选择不同的联邦基地、殖民地、前哨或矿场作为起终点。接受时预留库存，抵达起点后装货，抵达终点后卸货。安全路线绕开已知接触与异常，途中更新；快速路线直达。安全不意味着能预知隐藏敌人。遭抢掠造成交付不足时不能获得完整任务成功。
- **探索**：调查地点、未知坐标或敌情。抵达后选择远距或近距；继续20游戏分钟未选择，采用创建时预设方案。近距采样提高精度、耗时和辐射／暴露风险；科学能力影响工作时间与成果。未变化地点重复调查仅更新记录，不重复发放科研奖励。

每个行动形成接受、准备、航行、执行、结算、返航、归档闭环。取消释放未装货预留；已装货物回港回收。达到舰体、护盾、能源或弹药撤退条件时，保全舰船优先。撤退期间不继续追击。

## 战斗与交战规则

护盾吸收伤害，剩余伤害进入舰体。攻击由武器射程、冷却、命中、能源和库存共同限制。Phaser／Pulse Phaser 消耗 Core Power；Photon／Quantum 发射时扣弹药，未命中不返还。护盾脱离交战后恢复，核心按舰型恢复。

| ROE             | 允许的行为                             |
| --------------- | -------------------------------------- |
| HOLD FIRE       | 永不开火，包括遭到攻击时               |
| RETURN FIRE     | 还击攻击本舰或正在保护的对象的敌人     |
| ENGAGE HOSTILES | 主动攻击已识别、确认敌对的接触         |
| WEAPONS FREE    | 主动攻击已识别非友军，仍不攻击未知信号 |

舰船失能后停止行动，由应急拖航送回泊位，舰体恢复到最低可维修状态。基地维修与装弹需要停靠及时间；材料不足采用较慢的基础保障。Starfleet 定期送达常规补给，这是 LV1 可持续游玩的保障，不是制造成长系统。

## 情报与隐形

UNKNOWN 不提供地图实体；CONTACT 只确认信号；CLASSIFIED 可提供阵营类别；IDENTIFIED 确认名称和舰型；TRACKED 表示充分跟踪。被动探测和消耗能源的主动扫描使用相同的引擎传感器规则。

基地覆盖290距离单位，舰船覆盖由舰型决定。覆盖圈只是探测能力示意，不能必然看穿隐形。罗慕兰隐形持续耗能并降低探测概率，隐形中不能开火；必须经过解除隐形过渡才能攻击，低能源自动解除。

失联保留 Last Known Position 与观测时间，位置冻结；30游戏分钟后从地图移除。历史身份和战报可以保留，但不提供当前坐标。渲染器收到的是引擎筛选后的情报、通信与可见交火特效，而非完整敌方世界。

## 海盗与罗慕兰的动机

海盗从地图边缘进入，通过己方感知判断货物价值、护航和距离，偏好弱防御货船与殖民地。可以夺取实际货物或殖民地补给；收益达标、遇到强防御或受损后撤退。不会在玩家抵达任务地点时突然贴脸生成。

罗慕兰以侦察和试探为主，Scout 主要观察；较强舰型可选择有利目标。没有合适目标时不攻击。对方并不因为是红色阵营就自动进入战斗。

默认命令只允许联邦空间；授权中立区或罗慕兰空间后才能跨境。路径、追击和修改后的授权均受引擎校验。撤退允许沿原路径返回联邦，不能因为撤销授权把舰船锁死在境外。

## 收益与下一轮

防御保全设施与运输窗口；运输增加实际库存，维修材料可恢复设施完整度；调查形成地图知识与情报并改善已知风险判断。科研、情报与配额保存为成果。成长系统、升级树、生产经济和模型操作者均留给后续等级，不以未实现功能作为本阶段验收成果。
